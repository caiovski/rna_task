O Problema: O Famoso Meme do Skyrim

Modelagem do Problema

O Módulo de Sobrevivência

Definimos duas entradas vitais para a tomada de decisão do NPC:

Entrada 1 (x₁): Vida do Inimigo (0% a 100%)
Entrada 2 (x₂): Distância até o Jogador (0m a 30m)
Saída Decidida (y):
0 = FUGIR / RECUAR (Buscar cobertura)
1 = ATACAR / LUTAR (Ir para o combate)

O Perceptron encontrará automaticamente a linha de equilíbrio que separa o momento seguro de lutar da necessidade vital de fugir.

Fundamentação Teórica

O Perceptron de Rosenblatt (1958)

  • O modelo pioneiro e bloco construtor de todas as redes neurais.
  • Soma Ponderada: Cada entrada recebe um peso de importância:
Soma = (Vida • w₁) + (Distância • w₂) + bias
  • Função Degrau (Ativação):
Se Soma ≥ 0 → 1 (Atacar)
Se Soma < 0 → 0 (Fugir)
Intuição Biológica:
Funciona exatamente como um interruptor ou potencial de ação biológico: só dispara quando os estímulos ponderados superam o limiar (bias).

Aprendizado Simples

Como o Perceptron Aprende? (Sem Derivadas!)

Diferente de redes neurais complexas, o aprendizado do Perceptron é puramente aritmético:

1. Cálculo do Erro:
Erro = y_real - y_previsto
(O resultado só pode ser 0, +1 ou -1)
2. Atualização dos Pesos:
w_novo = w_antigo + (η • Erro • x)
bias_novo = bias_antigo + (η • Erro)
  • Se acertou (Erro = 0): Nada se altera.
  • Se deveria fugir mas atacou (Erro = -1): Os pesos são reduzidos.
  • Se deveria atacar mas fugiu (Erro = +1): Os pesos são aumentados.
Zero derivadas parciais, zero matrizes complexas! Apenas soma e multiplicação.

Discussão Crítica

Por que o Perceptron Simples e não o MLP?

Por que o Perceptron foi ideal aqui?
O problema de vida vs distância é linearmente separável. Uma única reta resolve 100% dos casos com custo computacional quase nulo em tempo real!
Quando precisaríamos de um MLP?
Se o problema fosse não-linear (ex: perigo em áreas circulares, poções no inventário, problema do XOR histórico de Minsky & Papert).
Aí seriam necessárias camadas ocultas e Backpropagation.
